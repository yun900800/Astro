1、一句话是通过词典进行切分的，那么这个词典是固定的还是可变的呢？ 固定的哈

2、一句话转化成序列以后，然后转化为向量以后，这里的维度是一个1 x N ,还是多维向量呢？每个词是一维向量，整句话是多维向量

3、单词“我”和h1的关系是怎么样的，状态是怎么更新的？

4、Encoder计算后的最终结果的维度是怎么样的？ 这个需要看情况，简单的只需要最后一个隐状态就是1 x N;而复杂的比如后来的注意力机制，就是 T x N ,这里的T是一句话包含多少单词；可能还需要并行计算，所以就有了批次 batchSize x T x N
5、为什么要进行矩阵运算而不是直接加法运算，毕竟它们的维度都是 1 x N。 因为x和h它们处于不同的空间，表达的意思是不同的，x所在的物理空间是“词向量空间（Embedding Space）”；h所在的物理空间是“记忆/状态空间（Hidden Space）”；所以矩阵计算更加合适。$W_{ih}$ 的作用，就是把 $x_1$ 从“天气表（词义）”转换成“人口表（内存状态）”。


-- 说明

一个形象的比喻：假设你手头有两张表格，形状都是 $1 \times 512$。
表 A 是**“中国城市天气表”**（512个城市，数字代表气温 $\text{}^\circ\text{C}$）。

表 B 是**“中国城市人口表”**（512个城市，数字代表万人）。

它们的维度完全一样，都是 $1 \times 512$。但你能在代码里直接把这两张表相加（气温 + 人口）吗？显然不能，因为加出来的数字没有任何物理意义。在公式中：$W_{ih}$ 的作用，就是把 $x_1$ 从“天气表（词义）”转换成“人口表（内存状态）”。$W_{hh}$ 的作用，则是负责把昨天的“人口表（旧记忆）”进行筛选和揉碎，看看哪些要留到今天。
